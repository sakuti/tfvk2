NÄIN PELI ON RAKENNETTU

Kevyt tekniikka.
Huolellinen pedagogiikka.

Peli toimii selaimessa ilman palvelinta tai maksullisia rajapintoja, myös offline-sovelluksena. Samat lähtöarvot ohjaavat kuvaa, tarkistusta, vihjeitä ja ratkaisua.

01 / SISÄLTÖ

Arvot vaihtuvat. Menetelmä säilyy.

Satunnaistus tarkistaa tasapainon, tukivoiman ja ajan rajat. Sini ja kosini määräytyvät aina kuvan kulman määritelmästä.

02 / OHJAUS

Kolme vihjetasoa.

Havainto → yhtälö → sijoitus. Sen jälkeen koko malliratkaisu nykyisillä arvoilla. Avustettu suoritus erotetaan itsenäisestä.

03 / KERTAUS

Heikko taito palaa uusilla luvuilla.

Lyhyet kierrokset, eri aiheiden yhdistely ja koeharjoitus. Osaaminen vahvistuu vasta useista itsenäisistä varianteista.

04 / TOTEUTUS

HTML + CSS + JavaScript.

SVG-kuvaajat ja voimanuolet, selaintallennus ja suhteelliset polut. Toiminta paikallisena kansiona sekä GitHub Pagesissa.
